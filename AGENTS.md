## Scope

This repository owns the public Céluma marketing site. Keep public claims accurate, understandable, and consistent with the current product and brand system.

## Required validation

- Install exact dependencies with `npm ci` when needed.
- Run `npm run lint` and `npm run build`.
- Review responsive layout, navigation, metadata, images, and changed external links.

## Safety boundaries

1. Do not publish unsupported clinical, security, compliance, pricing, or availability claims.
2. Use approved brand assets and synthetic content only. Never include PHI, secrets, internal URLs, or production exports.
3. Do not commit, push, merge, tag, publish, or deploy unless Rafael explicitly requests that exact action.
4. Record validation results and any browser or device checks that were not run.
